# KD İmsakiye

**KD İmsakiye**, modern Android teknolojileri kullanılarak geliştirilmiş, Ramazan ayı ve günlük namaz vakitlerini takip etmenizi sağlayan kullanıcı dostu bir mobil uygulamadır.

## 🚀 Özellikler

*   **Dinamik Arayüz:** Günün vaktine göre otomatik değişen (Gündüz/Gece) temalar.
*   **Hicri ve Miladi Takvim:** Hem hicri hem miladi tarihleri bir arada görüntüleme.
*   **Akıllı Geri Sayım:** İftar ve İmsak vakitlerine kalan süreyi saniye hassasiyetinde takip edin.
*   **Otomatik Konum Belirleme:** GPS üzerinden bulunduğunuz şehre göre vakitleri anında güncelleyin.
*   **Manuel Şehir Seçimi:** Türkiye'deki tüm iller için manuel seçim imkanı.
*   **Gelişmiş Bildirim Sistemi:**
    *   İftar ve Sahur öncesi özelleştirilebilir hatırlatıcılar.
    *   Vakit geldiğinde ezan ve davul sesli uyarılar.
    *   Canlı geri sayım (Live Countdown) bildirimleri.
*   **Yıllık Veri Önbelleğe Alma:** Verileri bir kez indirip çevrimdışı kullanım imkanı.

## 🛠 Kullanılan Teknolojiler ve Kütüphaneler

*   **Dil:** Kotlin
*   **Mimari:** Android Framework (View-based UI)
*   **Ağ İşlemleri:** Retrofit & Gson (Diyanet uyumlu API entegrasyonu)
*   **Asenkron Programlama:** Kotlin Coroutines
*   **Veri Saklama:** DataStore Preferences
*   **Konum Servisleri:** Google Play Services Location
*   **Arka Plan İşlemleri:** AlarmManager & WorkManager
*   **UI Bileşenleri:** Material Components, Splash Screen API, Lottie (Opsiyonel)

## 📦 Kurulum

Projeyi yerel makinenizde çalıştırmak için şu adımları izleyin:

1.  Depoyu klonlayın:
    ```bash
    git clone https://github.com/kullanici_adi/uxtest.git
    ```
2.  Android Studio'yu açın.
3.  "Open an Existing Project" seçeneği ile proje dizinini seçin.
4.  Gradle senkronizasyonunun tamamlanmasını bekleyin.
5.  Uygulamayı bir emülatör veya fiziksel cihazda çalıştırın.
